# Security Policy

Although this repository contains **documentation only**, the following guidelines apply.

---

## Scope  
This project does not include:  
- executable code  
- algorithms  
- models  
- data pipelines  

Therefore, no software vulnerabilities are expected.

---

## Reporting Issues  
If you identify:  
- incorrect information  
- misleading documentation  
- conceptual inconsistencies  

please open an Issue on GitHub.

---

## Responsible Use  
All documentation must be used ethically and academically.  
No proprietary or confidential information may be inferred or reconstructed from this repository.
