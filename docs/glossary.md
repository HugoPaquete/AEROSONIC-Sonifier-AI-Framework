# Glossary

This glossary defines key terms used throughout the **AEROSONIC Sonifier — AI Framework** documentation.  
All definitions are conceptual and do not reveal implementation details.

---

## AEROSONIC Sonifier
A real‑time meteorological sonification system that transforms environmental data into dynamic musical behaviour.

## AI Framework
The conceptual layer of artificial intelligence that mediates between meteorological input and musical output.

## Agent
A conceptual component responsible for a specific behavioural, analytical or generative function within the system.

## Weather Agent
The agent that interprets meteorological data and extracts meaningful environmental features.

## Anomaly Detector
The agent that identifies rare, unexpected or statistically unusual environmental conditions.

## Dreaming AI
A generative agent responsible for imaginative variation, emergent behaviour and exploratory tendencies.

## Quantum State Agent
The agent that manages stochastic transitions, probabilistic weighting and collapse events.

## Harmonic Field Agent
The agent that defines harmonic regions, tonal behaviour and harmonic evolution.

## Rhythm Engine
The agent that produces rhythmic structures, temporal patterns and rhythmic density.

## State Machine
The coordinating agent that manages global system behaviour, transitions and macro‑structure.

## Behavioural Layer
The multi‑agent ecosystem responsible for generative, adaptive and emergent musical behaviour.

## Musical Output Layer
The conceptual layer that translates AI directives into musical transformations within the sonification engine.

## Conceptual Mapping
The abstract relationship between environmental conditions, agent behaviour and resulting musical states.

## Emergent Behaviour
Global system behaviour that arises from the interaction of multiple agents rather than explicit programming.

## Stochastic Transition
A probabilistic change between states influenced by environmental conditions and agent interaction.

## Environmental Input Layer
The conceptual layer responsible for sensing, interpreting and contextualising meteorological data.

## Behavioural Output
High‑level musical directives generated by the AI agents before being translated into sound.
